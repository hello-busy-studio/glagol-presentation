# glagol-presentation

Система для сборки презентаций **бюро Глагол** в PowerPoint с помощью ИИ.
Презентации получаются в фирменном стиле Глагола, а работа с клиентом укладывается в два круга.

## Что внутри

| Путь | Что это |
|---|---|
| [`DESIGN.md`](DESIGN.md) | **Источник правды.** Дизайн-система и инструкция для ИИ: процесс работы с клиентом, цвета, типографика, сетка, компоненты, каталог типов слайдов с координатами, рецепты графики, код сборки, чек-лист QA. |
| `Шаблон презентации.pptx` | Исходный шаблон: слайды 1–15 — гайдбук бренда, 16–93 — шаблоны слайдов по типам. Каждый тип начинается со своего заголовочного слайда. |
| `assets/` | Готовые PNG из шаблона: логотипы, знак, навигация, градиенты, линии, маски-стрелки, мокапы, QR. |
| `reference/slides/` | Превью всех 93 слайдов шаблона для визуальной сверки. |
| `tools/build_test_deck.py` | Пример скрипта (python-pptx): собирает презентацию из шаблона — дублирует слайды, меняет текст без потери стиля, ставит заглушки. |

Главный файл — `DESIGN.md`. Он самодостаточен: по нему можно собрать презентацию с нуля, даже без шаблона и ассетов.
Шаблон и `assets/` ускоряют работу. Если они расходятся с документом, прав `DESIGN.md`.

## Как пользоваться

### Если ты собираешь презентацию через ИИ (Claude Code и т.п.)

1. Открой ИИ-агента в папке этого репозитория.
2. Напиши примерно так:

   > Собери презентацию по DESIGN.md. Тема: «…». Вот материалы: …

   Если материалов пока нет, напиши: «начни с брифа». Агент пришлёт клиенту список того, что нужно:
   тексты, спикер, фото, цифры, цитаты, ссылки для QR.
3. Агент работает по процессу из раздела «П» в `DESIGN.md`:
   - **Бриф** — запрос материалов. Чего нет, то заменяется заглушками `[…]`.
   - **Круг 1** — сдаёт `<Тема> — v1.pptx` и PDF, структуру презентации и список заглушек,
     просит правки списком «Слайд N. …».
   - **Круг 2** — вносит правки и отчитывается по каждому пункту. Это финальная версия.

### Формат правок для клиента

```
Слайд 1. Заголовок: «…».
Слайд 3. Убрать пункт 04.
Слайд 5 и 6. Поменять местами.
После слайда 9. Добавить цитату: «…» — Имя Фамилия.
Общее. Обложку сделать тёмной.
```

## Требования

- **PowerPoint.** Слайд 16:9 размером **10 × 5.625 in** — это размер Google Slides, а не стандартный 13.33 × 7.5.
- **Шрифт Wix Madefor Display** (бесплатный, [Google Fonts](https://fonts.google.com/specimen/Wix+Madefor+Display)).
  В шаблон он встроен. В новых файлах его нужно встроить через PowerPoint («Внедрить шрифты») или установить у получателя.
- **Сборка кодом:** Python 3 + `python-pptx` или Node + `pptxgenjs`. Примеры — в разделе 9 `DESIGN.md`.

## Как менять систему

- Все правила меняются в `DESIGN.md`. Если поменялся бренд или шаблон, сначала обнови документ, потом при необходимости
  ассеты и шаблон.
- Изменения — через ветку и PR в `main`, по одной задаче на PR.
- Нашли расхождение шаблона с документом — поправьте документ или отметьте в нём, какой вариант правильный.
